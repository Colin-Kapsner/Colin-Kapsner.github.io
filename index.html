Software Design and Engineering

Inventory Management Android Application

For my first enhancement, I focused on improving the software design and organization of my Android inventory management application. The focus of this enhancement was to separate responsibilities within the application and improve the general user experience, as well as prepare the app for future enhancements.

Improvements included creating an InventoryItem model, separating login and inventory responsibilities, improving input validation and navigation, and restructuring the inventory display using RecyclerView.

Algorithms and Data Structures

Inventory Search and Sorting

For my second enhancement, I added searching and sorting functionality to the inventory application. Inventory records are managed using an ArrayList of InventoryItem objects.

The application uses linear search to find inventory items by name and a custom merge sort implementation to sort items by name or quantity in ascending or descending order. The algorithms were separated into an InventoryAlgorithms class to keep algorithm logic separate from the user interface.

Databases

Database Enhancement

For the database enhancement, I improved the structure of the application's SQLite database by creating relationships between users, inventory items, and inventory history. Inventory items are now associated with the user who created them, allowing each user to maintain a separate inventory within the same database. I also added an inventory history table that records quantity changes of items.

This enhancement gave me more experience with relational database design and data integrity. I implemented primary and foreign keys, foreign-key constraints, and cascading deletion. I also updated the application's database operations so users can only view and modify their own inventory.
